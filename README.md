# ✏️ Handwritten Digit Classification with Keras & TensorFlow

This project demonstrates how to **build, train, and evaluate a neural network** using **Keras (TensorFlow backend)** to classify handwritten digits from the **MNIST dataset**.  

The MNIST dataset contains **70,000 grayscale images** of handwritten digits (0–9), each sized **28×28 pixels**. The goal is to correctly classify each image into one of the **10 digit categories**.

---

##  Features
- Load and preprocess the **MNIST dataset**  
- Build a **deep neural network** using the Keras Sequential API  
- Train the model with **training data** and validate performance  
- Evaluate **accuracy** on the test dataset  
- Visualize **predictions** for sample images  

---

##  Tech Stack
- Python 🐍  
- TensorFlow / Keras  
- NumPy  
- Matplotlib (for visualization)  
- Jupyter Notebook / Google Colab  

---

##  Project Workflow
1. Import required libraries  
2. Load and normalize MNIST dataset  
3. Build the **Sequential neural network** model  
4. Compile the model with **optimizer, loss function, and metrics**  
5. Train the model with training and validation sets  
6. Evaluate model performance on the test set  
7. Visualize predictions alongside actual images
